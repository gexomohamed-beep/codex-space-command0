# CODEX SPACE COMMAND

Vercel-ready static HTML app with a secure server-side AI proxy.

## Environment Variable
Set `CODE_API_KEY` in Vercel Environment Variables. The key is never embedded in `index.html`.

## Supported providers
- Gemini (`sk-...`)
- Gemini (`sk-ant-...`)
- Google Gemini (`AIza...`)


## Gemini
This version uses Google Gemini only. Set `CODE_API_KEY` in Vercel to your Gemini API key. The key stays server-side.
